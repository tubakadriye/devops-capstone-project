# devops-capstone-project

![Build Status](https://github.com/tubakadriye/devops-capstone-project/actions/workflows/ci-build.yaml/badge.svg)


This project develops a customer account microservice for an e-commerce website using Python and Flask. It provides a REST API to create, read, update, delete, and list customer accounts.

The starter code includes a database model and an endpoint for creating customer accounts. This project extends the service by adding endpoints to read, update, delete, and list accounts.

The work includes preparing the development environment, planning tasks, implementing and testing the API, and applying DevOps practices.
